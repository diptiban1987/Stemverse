# Robotics Learning Ecosystem PRD (Scratch → Robotics → AI → Industry)

# Vision

Create a complete learning-to-building ecosystem where a beginner starts with Scratch-style block coding and gradually progresses to robotics, IoT, AI, ROS2, industrial automation, and professional engineering workflows—all inside one platform.
