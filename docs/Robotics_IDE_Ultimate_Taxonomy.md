# Design Rules

- Use configurable blocks.
- Avoid duplicate sensor blocks.
- Use dropdowns and inline editors.
- Generate Arduino, ESP-IDF, MicroPython, CircuitPython, STM32, and ROS code.
- Support plugin architecture.
- Target 1000+ logical capabilities using 300–500 configurable visual blocks.

This taxonomy is suitable for building a commercial-grade robotics and IoT visual programming platform in Next.js.
