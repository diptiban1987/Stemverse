# STEMVerse Competition Guide (Robothrone)

## Competition Types
- **Standard**: Open circuit building competition
- **Robothrone**: Robot programming challenges
- **Hackathon**: Timed build events
- **Classroom**: Teacher-organized challenges

## Creating a Competition
1. Create competition with title and description
2. Define categories (robotics, circuits, coding)
3. Assign judges to categories
4. Open registration for teams
5. Accept submissions
6. Run judging with scoring rubrics
7. Generate leaderboard
8. Issue certificates to winners
9. Award achievements and XP

## Judging System
- Multi-judge scoring per category
- Score criteria with weights
- Tie-breaking by earliest submission
- Average score calculation
- Automatic leaderboard generation

## Leaderboard Scopes
| Scope | Description |
|-------|-------------|
| Competition | Event-specific rankings |
| School | School-level rankings |
| District | District-wide rankings |
| Regional | Geographic region |
| National | Country-level |
| Global | Platform-wide |

## Rewards
- XP: 50 per competition participation
- Achievement: "First Win" (uncommon), "Champion" (epic)
- Certificates: Participation and winner certificates
- Coins: Challenge completion rewards
- Leaderboard: Permanent ranking history

## Season System
- Season-based competition periods
- Cumulative season rankings
- Season-end rewards and certificates
- History tracking across seasons
