# STEMVerse Enterprise Guide

## License Types
| Type | Seats | Annual Price | Features |
|------|-------|-------------|----------|
| Free | 5 | $0 | Simulator, basic projects |
| Starter | 25 | $99 | + Marketplace browse |
| School | 200 | $499 | + Classrooms, competitions, certs |
| District | 5,000 | $2,999 | + Analytics, multi-school, branding |
| Enterprise | 50,000 | $9,999 | + API, SSO, white-label, priority |

## Enterprise Onboarding
1. **License Setup**: Create enterprise license with seat allocation
2. **Subscription**: Configure billing (Stripe/Razorpay/PayPal/PO)
3. **White Label**: Custom domain, logo, colors, email templates
4. **Organization**: Create org structure with departments/campuses
5. **Users**: Bulk import students and teachers
6. **Classrooms**: Set up class structure and curriculum
7. **Quotas**: Configure usage limits per plan
8. **Monitoring**: Health scoring and engagement tracking

## White Label Options
- Custom domain (CNAME setup)
- Custom logo and favicon
- Custom color scheme (primary/secondary/accent)
- Custom email templates
- Custom certificate templates
- Custom login page
- Custom footer/copyright text
- 5 preset themes available

## Customer Success
- Health scoring (healthy/at_risk/critical/churned)
- Engagement scoring (0-100)
- Contract management with auto-renewal
- Renewal forecasting (monthly/quarterly)
- Contact management with primary contacts
