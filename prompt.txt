Implementation Plan — Phase 7U — Visual Wire & Connection Layout Foundation

Implement a deterministic, serializable, browser-safe visual wire metadata foundation for @stemverse/runtime-engine.

IMPORTANT

This phase DOES NOT implement:

* actual wire rendering
* SVG rendering
* Pixi graphics rendering
* wire routing algorithms
* drag-and-drop wire editing
* electrical simulation
* voltage/current calculations

This phase ONLY implements:

* wire metadata
* wire path ownership
* wire layout synchronization
* serialization
* renderer synchronization

==================================================
GOAL
====

Allow RuntimeConnection objects to own visual layout metadata.

Examples:

ESP32 GPIO2
───── wire ─────
LED INPUT

BUTTON OUTPUT
───── wire ─────
ESP32 GPIO4

Only metadata.

No rendering.

==================================================

1. TYPES
   ==================================================

[MODIFY]

packages/runtime-engine/src/types/index.ts

Add:

export interface WirePoint {
x: number;
y: number;
}

export interface WireLayout {
connectionId: string;

points: WirePoint[];

color?: string;

thickness?: number;

visible: boolean;
}

Extend StageSyncState:

Extend SerializedTarget:

wireLayouts?: WireLayout[];
