# Release Notes — STEMVerse v1.0.0-beta

## 🚀 First Public Beta Release

STEMVerse v1.0.0-beta is the first public release of the STEMVerse electronics simulation and STEM education platform.

## Highlights

### For Students
- Build real circuits on an interactive virtual breadboard
- Program robots with Blockly visual coding
- Earn XP, level up, and unlock rewards
- Compete in Robothrone competitions
- Track streaks and complete daily challenges

### For Teachers
- Create and manage classrooms with invite codes
- Design assignments with auto-grading
- Track student progress with learning analytics
- Issue verifiable certificates
- Organize classroom competitions

### For Schools
- Multi-classroom management
- Student enrollment and progress tracking
- Competition hosting (Robothrone)
- Marketplace for curriculum resources
- Certificate programs

### For Enterprise
- White-label deployments with custom branding
- Multi-tenant licensing (up to 50,000 seats)
- Subscription billing with multiple payment providers
- Usage quotas and monitoring
- Customer success management with health scoring
- Contract management and renewal forecasting

- WebSerial requires Chrome/Edge browser
- Offline mode requires initial online load
